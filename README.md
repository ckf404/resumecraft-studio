# ResumeCraft Studio

افتح `index.html` في متصفح حديث. اترك ملفات المكتبات المرفقة في المجلد نفسه؛ التطبيق يعمل محليًا ولا يحتاج تنزيل مكتبات التصدير عند كل مرة.

## ما يتضمنه

- قوالب متعددة، عربية وإنجليزية، مع معاينة مباشرة وتغيير اللون.
- إدخال يدوي أو لصق بيانات جاهزة، أو استيراد نص من TXT وPDF النصي وDOCX.
- حفظ الطلب تحت اسم العميل ورقم هاتفه، مع حالة «قيد الإعداد» أو «جاهز للإرسال» أو «تم الإرسال»، ثم استدعاؤه أو حذفه.
- تصدير PDF من العرض المصوّر نفسه لتفادي الصفحات البيضاء، وإنشاء Word من صور الصفحات للمحافظة على شكل المعاينة.
- مشاركة الملفين من قائمة مشاركة الهاتف؛ يختار المستخدم WhatsApp والمحادثة ويؤكد الإرسال بنفسه.

## تنبيهات مهمة

- Word يحافظ بصريًا على المعاينة لكنه يحتوي صور صفحات غير قابلة لتحرير النص. PDF أيضًا يحافظ على المظهر عبر صور الصفحات.
- مشاركة WhatsApp لا ترسل تلقائيًا إلى رقم دون اختيار المحادثة والتأكيد؛ هذا قيد أمان يفرضه المتصفح وWhatsApp. إذا لم تظهر مشاركة الملفات، نزّل الملفين وأرفقهما يدويًا.
- العملاء محفوظون محليًا في تخزين المتصفح على الجهاز والمتصفح نفسيهما، وليسوا قاعدة بيانات مشتركة. لا تمسحي بيانات المتصفح إذا أردت الاحتفاظ بهم.
- استيراد ملفات PDF الممسوحة ضوئيًا كصور يحتاج OCR؛ الاستيراد الحالي مخصص للملفات النصية.
- الاتصال الآلي بالذكاء الاصطناعي لا يمكن تضمين مفتاحه بأمان في ملف HTML ثابت. يوفر التطبيق زرًا لنسخ طلب الصياغة إلى مساعد تختارينه، ثم لصق JSON الناتج وتطبيقه. التشغيل الآلي يتطلب خادمًا آمنًا ومفتاح خدمة محفوظًا عليه.
