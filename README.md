# ResumeCraft Studio

افتح `index.html` في متصفح حديث. احتفظ بكل الملفات في المجلد نفسه؛ ملفات DOCX وPDF ومكتبات PDF مرفقة محليًا.

## الميزات
- 6 قوالب سيرة ذاتية، عربي/إنجليزي، ومعاينة مباشرة.
- تغيير اللون الأساسي للقالب.
- إدخال يدوي أو لصق بيانات/استيراد ملف نصي أو PDF قابل لتحديد النص، مع استخراج أولي للحقول الشائعة.
- حفظ السير محليًا في المتصفح، وإعادة فتحها أو حذفها.
- تصدير PDF وWord، وإضافة صور الشهادات.
- فتح واتساب برسالة جاهزة. يجب تنزيل الملفات وإرفاقها يدويًا؛ المتصفح لا يتيح إرسال المرفقات تلقائيًا عبر رابط واتساب.

## ملاحظات
- البيانات المحفوظة تبقى في تخزين المتصفح على الجهاز نفسه، وليست قاعدة بيانات مشتركة.
- استيراد PDF يعمل مع الملفات النصية. ملفات المسح الضوئي تحتاج OCR؛ وملفات DOC/DOCX ليست ضمن استيراد النص حاليًا.
- الصياغة بالذكاء الاصطناعي تتطلب بيئة Claude التي يوفرها المضيف الحالي؛ فتح HTML محليًا وحده لا يوفر اتصالًا آمنًا بخدمة ذكاء اصطناعي أو مفتاح API.
- يفضّل استخدام Chrome أو Edge لفتح الملف وتصدير PDF وWord. وقد تختلف الخطوط قليلًا حسب الجهاز، لذلك افحص PDF الناتج قبل إرساله.
